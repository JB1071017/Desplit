# DeSplit

A unified monorepo containing the DeSplit application ecosystem.

## Repository Structure

- **`desplit/`**: Flutter mobile application for expense splitting and settlement.
- **`petals/`**: Decentralized inference platform and distributed compute backend.
- **`plexo/`**: Open-source task management and workflow system.
- **`.qodo/`**: Development agents and workflows configuration.
